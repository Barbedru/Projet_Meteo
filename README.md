🌤️ Projet Météo

Exercice de découverte de Vue.js réalisé dans le cadre de la formation Concepteur Développeur d'Applications (CDA).


📖 Description
Ce projet est une application météo développée en Vue.js. Il s'agit d'un exercice pratique dont l'objectif est de se familiariser avec les bases du framework Vue.js : composants, gestion des données, appels API et affichage dynamique.

🎯 Objectifs pédagogiques

Découvrir la structure d'un projet Vue.js
Comprendre le système de composants Vue
Pratiquer la communication avec une API externe (météo)
Manipuler les données réactives (data, computed, methods)
Afficher dynamiquement des informations dans le DOM

🚀 Installation et lancement
Prérequis

Node.js (version 14 ou supérieure)
npm (inclus avec Node.js)

Étapes
bash# 1. Cloner le dépôt
git clone https://github.com/Barbedru/Projet_Meteo.git

# 2. Se déplacer dans le dossier du projet Vue
cd Projet_Meteo/premier_projet_vue

# 3. Installer les dépendances
npm install

# 4. Lancer le serveur de développement
npm run serve
L'application sera accessible à l'adresse : http://localhost:8080
